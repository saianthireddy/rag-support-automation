# Security Policy

## Credential resets

Password resets for customer administrators require verification against the
account contact on file. Never reset an administrator credential based on an
inbound email request alone, regardless of how urgent the sender claims it is.

## Reporting a suspected breach

A suspected breach is not the same as a customer reporting lost data. If there
is any indication of unauthorised access, notify the security team through the
dedicated channel rather than opening a normal incident, and do not discuss the
details in the shared support queue.

## Data retention

Customer telemetry is retained for ninety days and then deleted automatically.
Backups of configuration data are held for one year. Deletion requests must be
recorded even when the data has already aged out.
